Le paladin est une classe assez particulière, qui cast ces sorts sur le charisme et qui peut soit sauver, soit se venger de ces ennemis éternels 

Caractéristique principale : constitution + charisme ou force + charisme
Dé de PV : 1d8
Dé de PE : 1d4

Il faut avoir +10 en Charisme pour multiclasser Paladin.
